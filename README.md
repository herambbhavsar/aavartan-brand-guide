# Aavartan — Brand Guide

Interactive brand guide website for **Aavartan**, the dance society of IIITDM Jabalpur.

Logo system and lockups, colour, type, events & sessions, dance forms, the mascot, poster series and archive, mockup library, the kit, element library, and a spray-paint wall.

Static site — open `index.html` or deploy as-is (no build step).
